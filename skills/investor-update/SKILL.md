# Investor Update

Use the filled [product parameters](../../PARAMETERS.md) at runtime; `{{PARAMETERS}}` means that filled block, not the blank template.

> **Shared rule:** Read the filled `{{PARAMETERS}}` block, current context and decision log. Separate fact, hypothesis, proposal and decision; give the source, date and scope for every number. Editorial approval never authorizes sending. If sources conflict, stop the claim/action and request a decision. Without a connected tool, access or evidence, report a draft/pending item—never pretend an action happened. Every external send requires specific human approval of the exact content, recipient, channel and sender.

## Objective

Communicate progress with facts, hypotheses and useful questions, without confusing activity with traction.

## When to use

Approved communication cycle to selected recipients.

## Inputs

{{PARAMETERS}}, authorized list, history, scorecard, validation milestones and decision log.

## Output

Draft by recipient/segment, auditable numbers, gaps and one specific ask.

## Human approval

Authorize exact version, recipient, sender and send individually.

## Common mistakes

Conflating pipeline with contract, pilot with revenue, interest with usage or target with result.

## Steps

1. Validate recipients, relationship and cadence; never add contacts by inference.
2. Check each number for source, period, denominator and evidence status; leave conflicts to confirm.
3. Draft factual headline, **Known / Testing / Unknown**, numbers and one specific ask.
4. Do not credit results to experiments not started; avoid unmeasurable unit-economics claims.
5. Run external text review; show the exact version to {{APPROVER}}; after a confirmed send, record responses and notify via the approved channel.

## Copy-paste prompt

> Draft an update for [authorized recipient] using {{PARAMETERS}} and [source references]. Structure known/testing/unknown, attach period and denominator to numbers and make one ask. List uncertainty and keep sending subject to approval.
