# Contributing

Issues and pull requests are welcome. Keep skills generic, independently usable and evidence-based. Do not include private data, personal contact details or live account identifiers in examples. Retain a separate, explicit human-approval gate before every external send; editorial review is not send authorization. Update the relevant documentation and check links, claims and privacy before proposing a change. Submissions are intended to be distributed under this repository's CC BY 4.0 license.
